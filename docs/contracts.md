# 数据及数值约定

图像输入float32/64，值域[0,255]，有效范围为左上有效height/width矩形。边缘块复制最邻近有效像素到8倍数；DCT为正交归一的二维II型，输入减128；逆变换后加128并裁剪[0,255]。候选量化表由调用方给出，元素正整数1..255，系数除表后ties-away-from-zero取整。输出是标准baseline sequential、8bit单分量JPEG，宽高等于有效范围，标准解码器可读取；模型输入取实际JPEG解码灰度值，数值DCT重建与解码结果允许每像素相差2。失真为sum(weight*(decoded-original)^2)/sum(weight)，权重非负且有效范围和>0。配置可行时选加权失真最小项，平局按配置id字典序；码率计算包含完整JPEG文件。反向替代量化导数为1，已饱和输出导数为0，边缘复制反向汇入对应源像素；空间权重用于调用者的损失输入，不擅自再次乘入上游梯度。JPEG编码器内部熵编码可以使用通用库，但DCT、量化及替代反向需在项目中可独立调用。

## 本地数据

张量文件为 JSON 对象，shape 指定维度，values 是按 C 连续顺序展开的一维元素，dtype 指定计算输入类型；空维度对应空 values。该格式描述输入，不要求产品内部采用相同存储。data/catalog.json 中的键是外部资料标识，路径相对于项目根。records 中用到的 tensor 字段均引用该标识。

events 中每组事件按列表先后应用，kind 表示调用方动作，字段给出所改变的身份、参数、版本或状态。重复事件不等于一份新业务对象，事件本身没有预置计算结果。数值注入事件的字符串 nan 表示在指定位置注入非有限浮点值；资料张量自身仍保存有限值。各组事件使用一份全新输入副本，组与组之间不共享状态。

## 较大输入

本地张量是便于人工核对的小尺寸合成输入。容量、工作区和容差承诺同样适用于调用方自行生成的支持范围内输入；不得按合成ID或具体数值特判。项目接口须接受符合约定的新张量与新身份。资料只声明输入含义，不预先提供推理、训练、状态迁移或输出答案。

PGM文件是images张量有效范围的无损原图副本，便于标准图像库核对资料，尚未提供JPEG输出。baseline JPEG 的熵编码及文件头遵循标准解码器兼容性；实际字节长度是包括所有头部和结束标记的文件长度。选择配置前不预置任何图像合格或失败结论。

较大输入配置中的数组只描述边界规模和分布，不含预定结果。生成后的index.json保留身份参数及数组规格，调用方可据本节字段构造产品请求。资源预算中的额外工作区不含调用方已提供的只读输入和最终输出，但包含内部副本、物化中间值、编码/反向重算临时量；不得把内部数组换个名称排除。
